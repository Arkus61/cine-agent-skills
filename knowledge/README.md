# Shared Film Knowledge

Keep detailed references beside the specialist that needs them so skill activation stays focused. Use this directory only for a carefully sourced principle shared by multiple skills.

Before adding shared material:

1. register the public source and access status in `docs/source-register.md`;
2. paraphrase general principles in original wording;
3. avoid screenplay pages, course text, transcripts, and proprietary shot breakdowns;
4. document which skills should load the reference;
5. retain any source-specific license or attribution requirement.

The v1.0 specialist references follow this source policy and require no bundled third-party teaching material.
