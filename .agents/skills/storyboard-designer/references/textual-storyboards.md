# Textual storyboard reasoning

## A board is a shot-by-shot visual plan

ACMI describes storyboards as a visual guide used before photography. Each panel represents what the camera sees in a shot; a board does not need to reproduce every frame. Use one panel for a stable shot state and add another only when a change cannot be communicated in the same drawing.

Source: [ACMI — Storyboards](https://www.acmi.net.au/education/school-program-and-resources/film-it-storyboards/).

## Make the panel drawable

Describe setting, characters, objects, and body language as they appear in the frame. Foreground, midground, and background make occlusion and depth explicit. Subject placement records where attention lands. Framing, angle, and camera height must inherit the shot plan.

## Make movement readable

ACMI recommends arrows for important character/object motion and separate border-adjacent arrows for camera movement. A textual board cannot draw the arrow, so state both the action direction and the movement state. Use frame-relative directions such as `Ninel turns toward frame right`; do not invent a compass bearing.

## Preserve production continuity

Every panel should identify the state that a later drawing or shot must match: hand placement, eye line, screen direction, prop state, lighting cue, practical state, or action phase. The board is not allowed to create new coverage or override an upstream continuity rule.

## Text only

This artifact is the instruction set for a storyboard artist or later visualization step. It deliberately contains no image prompt, URL, base64 payload, or generated media. Unknown appearance and design details belong in assumptions, not descriptive invention.
