# Shot acceptance

Review only dimensions that the prompt or supplied media makes applicable: composition, performance, identity, action, movement, light, continuity, sound, artifacts, and declared acceptance criteria. Record a pass, fail, or not-assessable outcome for each declared criterion and cite the evidence that supports a pass or fail.

Use `approved` only when every declared criterion has applicable evidence and passes with no unresolved deviation. Use `repair` for a bounded localized correction. Use `regenerate` when the mismatch is foundational. Use `human-review` for subjective interpretation or rights/safety judgment, with a specific question for the qualified human. A report is `blocked` when evidence or a subjective/rights/safety issue prevents a review disposition; it is not an approval.
