# Media review evidence

Treat an inspected file and its measured metadata as different evidence. Record the input identity and full SHA-256 fingerprint before making a claim. A filename, location, prompt, expected result, or creator description identifies context but does not demonstrate a criterion.

| Input modality | May support | Cannot support |
| --- | --- | --- |
| Still | Static composition, visible performance, identity, action state, light, continuity, and static artifacts | Movement, timing, temporal artifacts, synchronization, or sound |
| Motion | Static visible criteria plus movement, timing, and temporal artifacts | Sound unless audio is present and inspected |
| Audio | Audible criteria and synchronization when paired with applicable motion | Visible composition, identity, light, or image artifacts |
| Measurable metadata | The named measured criterion only | Unnamed or visual/audible criteria by inference |

Bind every evidence claim to one exact input and one declared acceptance criterion. State uncertainty where evidence is incomplete; do not convert missing evidence into a failure, pass, or invented observation.
