# Beat Analysis Reference

## Beat boundary signals

Create a new beat when at least one of these changes materially:

- objective or immediate sub-objective;
- tactic;
- possession of important information;
- power relationship;
- emotional value;
- physical relationship to the space;
- tempo or interruption pattern.

A pause alone is not necessarily a beat. A line of dialogue alone is not necessarily a beat. The unit is a change in dramatic action.

## Evidence versus interpretation

Write evidence as observable script material: action, dialogue, silence, entrance, exit, prop use, or revealed information. Write interpretation separately as tactic or value shift. This prevents the agent from turning a plausible reading into a false script fact.

## Value shifts

Describe values as directional changes, for example:

- trust to suspicion;
- control to vulnerability;
- isolation to connection;
- certainty to doubt;
- concealment to exposure.

## Visual opportunity

A visual opportunity is a possibility, not a shot command. Good examples identify a relationship that could be externalized: increasing distance, blocked eyeline, contested object, repeated threshold, or changing access to light.
