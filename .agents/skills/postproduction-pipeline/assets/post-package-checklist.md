# Post Package Checklist

- [ ] Upstream production and media-review validation is current.
- [ ] Edit is the first post artifact and every downstream record references its current ID.
- [ ] Sound, music, VFX post, and color follow the edit; titles/captions follow the edit; mastering/QC is last.
- [ ] Each item distinguishes `planned` work from supplied evidence; no approval or measurement is inferred.
- [ ] `validate-post` was run with its real command, exit code, profile, result, and errors preserved.
- [ ] Repair starts at the earliest invalid dependency and preserves valid unaffected records.
- [ ] Handoff is exactly `planned`, `ready-for-master-review`, or `blocked`.
