# Prompt continuity

Use immutable anchors for features that cannot drift and allowed variation for bounded changes. Tie both to upstream IDs and source records. Continuity anchors name observable carryover across prompts: identity, wardrobe, action state, environment, light relationship, sound perspective, or music entry/exit.

Each prompt has negatives that prevent known drift and criteria that another reviewer can inspect. Do not convert a proposal, assumption, or uncertainty into a supplied fact or approval.
