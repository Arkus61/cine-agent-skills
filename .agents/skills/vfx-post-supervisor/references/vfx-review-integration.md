# VFX Review and Integration

## Review the exact version

Identify the item and output version before recording a note or decision. Inspection evidence states what supplied media was reviewed. Human-approval evidence records the authorized decision for that same item and version. A note on v006 cannot approve v007, and a filename alone cannot prove either version was inspected.

Review the composite in shot and edit context. Check purpose, temporal continuity, edges, occlusion, track stability, motion blur, defocus, grain, lens response, light and shadow, reflections, atmosphere, contact, and transitions into adjacent segments. Convert observations into version-bound actions.

## Coordinate downstream handoff

State color-pipeline and viewing assumptions without inventing measured input properties. Identify the outgoing version and declared target, plus any mattes or supporting elements expected by color and finishing. If the target changes, re-verify against the new target.

Delivery verification is distinct from creative approval. Mark delivery `verified` only when evidence binds the exact post item, current version, and declared target. Keep unresolved checks in assumptions or uncertainties; do not infer success from transfer, naming, or verbal completion.
