# Changelog

All notable changes are recorded here.

## 2.0.0 — 2026-09-15

- Added the layered v2 planning core for story, screenplay, creative production, and postproduction, with deterministic `validate-project` integration checks.
- Added the exact thirty-seven-skill catalog: twelve preserved v1 skills and twenty-five v2 skills, including the full creative orchestrator.
- Added the canonical Ninel v2 structural demonstration (`series` + `animation` + `ai`) and explicit `awaiting-media` evidence state.
- Added v2 layer/project documentation, an additive v1-to-v2 migration guide, explicit Make validation targets, and a deterministic tracked-file release archive builder.
- Preserved `core-v0.1`, `full-v1`, their schemas and examples, and all existing scene-level CLI contracts unchanged.
- Kept media generation, external APIs, Blender/NLE execution, freshness comparison, publishing, and producer operations outside this planning release.

## 1.0.0 — 2026-08-05

- Added visual-language, lighting, sound, storyboard, production-breakdown, and continuity specialist skills.
- Expanded the canonical catalog to twelve independently usable skills.
- Added six creative artifact schemas and a deterministic package-manifest schema.
- Added the thirteen-file `full-v1` package profile while preserving `core-v0.1` compatibility.
- Added automatic profile selection and deterministic JSON validation reports.
- Added full-package identifier, cross-reference, coverage, and manifest validation.
- Added a complete full-v1 Ninel example and explicit core/full Make validation targets.
- Upgraded the orchestrator to create, repair, validate, and hand off the complete v1 package.

## 0.1.0 — 2026-08-05

- Added the original five creative specialist skills and scene preproduction pipeline.
- Added five artifact schemas, repository validation, package validation, and the core Ninel example.
